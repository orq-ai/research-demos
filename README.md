# research-demos

Public demo gallery for the Orq Research team. Self-contained HTML/PDF artifacts published via GitHub Pages.

**Live:** https://orq-ai.github.io/research-demos/ (enable Pages first)

## Adding a demo

See [docs/conventions.md](docs/conventions.md).

## Structure

- `index.html` — gallery (hand-written cards)
- `demos/<slug>/` — one folder per demo: cover `index.html` + `manifest.json` + artifact files
- `assets/` — shared `shell.css`, favicon, OG image, pandoc template

## Brand

Ivory / slate / clay palette, serif/sans/mono stack. Tokens lifted from the `html-artifacts` skill — see `assets/shell.css` `:root`.
